複数端末で同期

スマホとPCなど、複数の端末で同じデータを見られるようにします。無料のFirebaseを使います。

はじめての設定手順（初回のみ・約5分）
  1. Firebase（console.firebase.google.com）にGoogleアカウントでログイン
  2. 「プロジェクトを作成」で新しいプロジェクトを作る（名前は何でもOK）
  3. 左メニュー Build → Authentication →「始める」→ Anonymous（匿名）を有効にする
  4. 左メニュー Build → Firestore Database →「データベースを作成」→ 本番モードで作成
  5. Firestoreの「ルール」タブを開き、下記に書き換えて「公開」：
    rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /spaces/{s}/items/{i} { allow read, write: if request.auth != null; } } }
  6. 歯車 ⚙ → プロジェクトの設定 → 下の「マイアプリ」で </>（ウェブ） を追加
  7. 表示される const firebaseConfig = {…} の {…} 部分をコピーし、下の欄に貼り付け
